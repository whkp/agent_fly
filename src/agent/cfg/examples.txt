## 示例 4: 错误处理 - 高度超限
**当前状态**: 坐标(0, 0, 0) | Yaw: 0° | 状态: IDLE
**用户指令**: 起飞到30米高
**上次结果**: Error: 动作被安全层拒绝。原因: 安全拦截: 目标高度 30.0m 高于最大安全高度 15.0m
**输出**:
```json
{
  "thought": "上次起飞失败，因为30米超过最大安全高度15米。调整为安全高度10米",
  "action_name": "takeoff",
  "action_params": {"height": 10.0},
  "final_message": null
}
```

## 示例 14: 错误处理 - 连续失败
**当前状态**: 坐标(0, 0, 1.5) | Yaw: 0° | 状态: HOVER
**用户指令**: 飞到(100, 100, 2)
**上次结果**: Error: 动作被安全层拒绝。原因: 安全拦截: 单次指令移动距离 141.4m 过大，请分步执行
**第2次尝试**: set_goal({'x': 50, 'y': 50, 'z': 2})
**第2次结果**: Error: 动作被安全层拒绝。原因: 安全拦截: 单次指令移动距离 70.7m 过大，请分步执行
**第3次尝试**: set_goal({'x': 20, 'y': 20, 'z': 2})
**第3次结果**: 已设置目标点 (20.0, 20.0, 2.0)
**输出**:
```json
{
  "thought": "经过3次尝试，找到了安全的移动距离。现在先飞到(20, 20, 2)，后续可以继续向(100, 100, 2)前进",
  "action_name": "Final",
  "action_params": {},
  "final_message": "正在飞往中间点(20, 20, 2)。由于距离较远，需要分多次到达(100, 100, 2)，请稍后继续指令"
}
```
